# AccelByte Unreal SDK

AccelByte Unreal SDK is a plugin for Unreal Engine. 

## Assumptions

This documentation assumes that you are already familiar with modern C++, Unreal Engine, HTTP, REST API, microservice architecture, OAuth2, OpenID Connect, JWT, WebSocket.

## Supported Unreal Engine

Engine versions supported by each release. Ranges are inclusive; `latest` means the most
recent [release](https://github.com/AccelByte/accelbyte-unreal-sdk-plugin/releases).

| Unreal Engine | SDK releases                              |
|---------------|-------------------------------------------|
| 4.26          | `23.5.0` – `24.4.1`                       |
| 4.27          | `23.5.0` – latest                         |
| 5.0 – 5.2     | `23.5.0` – `28.6.0` (removed in `28.7.0`) |
| 5.3           | `24.5.0` – `28.6.0` (removed in `28.7.0`) |
| 5.4           | `28.1.0` – `28.6.0` (removed in `28.7.0`) |
| 5.5           | `28.1.0` – latest                         |
| 5.6           | `28.1.0` – latest (Beta until `28.5.1`)   |
| 5.7           | `28.5.1` – latest (Beta until `28.9.0`)   |
| 5.8           | `28.9.0` – latest                         |
